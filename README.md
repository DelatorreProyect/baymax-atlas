# Baymax · Atlas anatómico (proyecto escolar)

Visor 3D interactivo de los sistemas del cuerpo humano, pensado para estudiar y exponer.
Elige un sistema y la anatomía real se proyecta como holograma dentro de Baymax. Cada pieza tiene su
nombre en español y latín (Terminologia Anatomica), definición, zoom y buscador. Funciona en computadora y celular.

> Proyecto escolar, sin fines de lucro.
